## 5.2 So sanh w2ui vs AG Grid

| w2ui (code cu) | AG Grid (code moi) |
|---|---|
| `w2ui.grid.records = [...]` | `rowData` state |
| `record.w2ui.changes` | AG Grid `onCellValueChanged` event |
| `w2ui.grid.columns.push(...)` | `columnDefs` state (dynamic) |
| `w2ui.children` (nested rows) | AG Grid Tree Data mode |
| `w2ui.grid.lock()` / `unlock()` | `loading` overlay |
| `w2ui.grid.refresh()` | React state update -> auto re-render |
| No virtual scroll | Virtual scrolling built-in (10K+ rows) |

## 5.4 Dynamic Language Columns

Tu `TranslationHandler.FillLanguageCodes()` (dong ~260-340):

```typescript
function buildColumnDefs(
  installedLanguages: LanguageLocale[],
  baseLanguage: number,
  lockedLanguages: number[],
  hideByDefault: boolean,
  userLanguage: number
): ColDef[] {
  const columns: ColDef[] = [
    // Column co dinh: Schema Name (khong edit)
    {
      field: 'schemaName',
      headerName: 'Schema Name',
      pinned: 'left',
      editable: false,
      width: 250,
      lockPosition: true,
    }
  ];

  // Language columns - 1 column per installed language
  for (const lang of installedLanguages) {
    const isLocked = lockedLanguages.includes(lang.localeid);
    const isBase = lang.localeid === baseLanguage;
    const isUserLang = lang.localeid === userLanguage;

    columns.push({
      field: `labels.${lang.localeid}`,
      headerName: `${lang.name} (${lang.code})${isBase ? ' [Base]' : ''}`,
      editable: !isLocked,
      width: 200,
      // An column neu config hideLanguagesByDefault = true, tru user language
      hide: hideByDefault && !isUserLang && !isBase,
      cellStyle: isLocked ? { backgroundColor: '#f5f5f5' } : undefined,
    });
  }

  return columns;
}
```

> **Tu code cu**: `XrmTranslator.GetColumns()` (dong ~755-785) quan ly logic show/hide columns.
> Config `hideLanguagesByDefault: true` -> chi hien base language va user language.
> Config `lockedLanguages: [1033]` -> column 1033 khong cho edit (read-only, xam).

## 5.5 Change Tracking

Thay the `record.w2ui.changes`:

```typescript
// State luu tru changes
const [changes, setChanges] = useState<Map<string, CellChange>>();

function onCellValueChanged(event: CellValueChangedEvent) {
  const rowId = event.data.id;
  const lcid = parseInt(event.colDef.field!.replace('labels.', ''));
  const change: CellChange = {
    rowId,
    lcid,
    oldValue: event.oldValue ?? '',
    newValue: event.newValue ?? '',
  };

  // Key = "rowId|lcid" de dam bao unique
  const key = `${rowId}|${lcid}`;
  setChanges(prev => {
    const next = new Map(prev);
    if (change.newValue === change.oldValue) {
      next.delete(key);  // Revert -> xoa change
    } else {
      next.set(key, change);
    }
    return next;
  });

  onCellChange(change);
}
```

## 5.7 Row Data Transform

Convert GridRow[] (handler output) sang AG Grid format:

```typescript
function flattenRows(rows: GridRow[], parentPath: string[] = []): FlatGridRow[] {
  const result: FlatGridRow[] = [];

  for (const row of rows) {
    const treePath = [...parentPath, row.schemaName];
    result.push({
      ...row,
      treePath,
    });

    if (row.children) {
      result.push(...flattenRows(row.children, treePath));
    }
  }

  return result;
}
```
