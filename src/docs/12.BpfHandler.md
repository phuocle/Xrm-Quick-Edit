## 12.1 Tong Quan

BPF (Business Process Flow) la workflow voi stages va fields. Handler nay:
1. Load tu `workflow.clientdata` (JSON chua labels tat ca ngon ngu)
2. Hien thi hierarchical: BPF -> Stage -> Field
3. Save bang **XAML string replacement** (KHONG dung DOM parser)
4. Phai deactivate workflow truoc khi update, activate lai sau

## 12.2 Load Logic

Tu `BpfHandler.Load()` (dong 338-377):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  // Query workflows: category eq 4 (BPF) AND primaryentity eq '{entity}'
  const workflows = await dataverseService.fetchRecords('workflow', {
    filter: `category eq 4 and primaryentity eq '${context.selectedEntity}'`,
    select: 'workflowid,name,clientdata',
  });

  const rows: GridRow[] = [];

  for (const wf of workflows) {
    if (!wf.clientdata) continue;

    let clientData;
    try {
      clientData = JSON.parse(wf.clientdata);
    } catch {
      continue; // Skip unparseable
    }

    // Parse stages va fields tu clientdata
    const children = parseStagesAndFields(clientData);

    rows.push({
      id: wf.workflowid,
      schemaName: wf.name,
      labels: {},
      children,
      meta: { workflow: wf },
    });
  }

  return { rows };
}
```

## 12.4 Save Logic — XAML String Replacement

Tu `SaveOnly()` (dong 408-496) — DAY LA PHAN PHUC TAP NHAT:

### Tai sao khong dung DOM Parser?

> Code cu comment: Browser DOM manipulates corrupt XAML structure (strips XML declaration, adds inline xmlns).
> String replacement giu nguyen byte-for-byte integrity.

### Algorithm: ApplyXamlUpdates (dong 215-283)

```typescript
function applyXamlUpdates(xaml: string, updates: BpfUpdate[]): string {
  let result = xaml;

  for (const update of updates) {
    // 1. Tim marker: <x:String x:Key="StageId">GUID</x:String>
    //    hoac <x:String x:Key="ProcessStepId">GUID</x:String>
    const markerRegex = new RegExp(
      `<x:String x:Key="${update.keyType}">${update.guid}</x:String>`
    );
    const markerMatch = result.match(markerRegex);
    if (!markerMatch) continue;

    const markerIndex = result.indexOf(markerMatch[0]);

    // 2. Tim nguoc ve: </sco:Collection> truoc marker (StepLabels closing tag)
    const collectionClose = '</sco:Collection>';
    const searchBackward = result.substring(0, markerIndex);
    const collectionIndex = searchBackward.lastIndexOf(collectionClose);

    // 3. Voi moi language change:
    for (const change of update.changes) {
      const lcid = change.lcid;
      const newText = escapeXml(change.newValue);

      // Tim label hien co cho language nay
      const labelRegex = new RegExp(
        `<mcwo:StepLabel[^>]*LanguageCode="${lcid}"[^>]*Description="([^"]*)"[^/]*/>`
      );

      const existingMatch = result.substring(collectionIndex, markerIndex).match(labelRegex);

      if (existingMatch) {
        // Update existing label
        const oldLabel = existingMatch[0];
        const newLabel = oldLabel.replace(/Description="[^"]*"/, `Description="${newText}"`);
        result = result.replace(oldLabel, newLabel);
      } else {
        // Insert new label truoc </sco:Collection>
        const newLabel = `<mcwo:StepLabel LanguageCode="${lcid}" Description="${newText}" />`;
        result = result.substring(0, collectionIndex) + newLabel + result.substring(collectionIndex);
      }
    }
  }

  return result;
}
```

### XML Escaping

```typescript
function escapeXml(text: string): string {
  return text
    .replace(/&/g, '&amp;')
    .replace(/"/g, '&quot;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;');
}
```

## 12.5 Workflow Lifecycle (CRITICAL)

```
1. Deactivate workflow (statecode=0, statuscode=1) — XAML chi writable khi Draft
2. GET workflow.xaml (backup cho rollback)
3. Apply XAML updates
4. PATCH workflow.xaml
5. Activate workflow (statecode=1, statuscode=2) — CRM validate + regenerate clientdata
```

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  for (const bpfRow of getChangedBpfs(rows, changes)) {
    const workflowId = bpfRow.id;
    let originalXaml: string | null = null;

    try {
      // 1. Deactivate
      await dataverseService.updateRecord('workflows', workflowId, {
        statecode: 0, statuscode: 1,
      });

      // 2. Backup XAML
      const wf = await dataverseService.retrieve('workflow', workflowId, ['xaml']);
      originalXaml = wf.xaml;

      // 3. Apply changes
      const updatedXaml = applyXamlUpdates(originalXaml, getUpdatesForBpf(bpfRow, changes));

      // 4. PATCH
      await dataverseService.updateRecord('workflows', workflowId, { xaml: updatedXaml });

      // 5. Activate
      await dataverseService.updateRecord('workflows', workflowId, {
        statecode: 1, statuscode: 2,
      });

    } catch (error) {
      // ROLLBACK: Restore original XAML va activate lai
      if (originalXaml) {
        try {
          await dataverseService.updateRecord('workflows', workflowId, { xaml: originalXaml });
          await dataverseService.updateRecord('workflows', workflowId, {
            statecode: 1, statuscode: 2,
          });
        } catch (rollbackError) {
          // "BPF may be stuck in Draft state; manual activation needed"
          throw new Error(`Rollback failed for BPF ${workflowId}. Manual activation required.`);
        }
      }
      throw error;
    }
  }
}
```

## 12.6 Edge Cases

| Edge Case | Xu Ly |
|---|---|
| clientdata khong parse duoc | Skip workflow, continue |
| XAML string replacement fail | Rollback ve original XAML |
| Rollback cung fail | Bao loi "manual activation needed" |
| XML special characters trong label | Escape &, ", <, > |
| Workflow dang bi deactivate boi nguoi khac | Error handling |
