# Overview - Xrm Quick Translate (PPTB Rewrite)

> Step-by-step implementation plan
> Source code: `src2/`
> Reference code: `src/js/` (code cu)

---

## Tong Quan

Viet lai Xrm Quick Edit thanh PPTB tool voi stack moi:
- **React 18** + **TypeScript**
- **AG Grid Community** (thay w2ui)
- **Fluent UI v9** (thay jQuery UI)
- **Vite** (build tool)
- **`@pptb/types`** + `window.dataverseAPI` + `window.toolboxAPI`

## Quy Tac Chung

1. **Moi handler la pure function** - nhan context, tra ve data. Khong goi UI truc tiep.
2. **mergeLabels: true** - Tat ca update metadata phai truyen flag nay.
3. **sanitizeForPut()** - Luon strip `versionnumber` truoc khi PUT.
4. **Doc code cu truoc khi viet** - Moi handler co reference den file cu tuong ung.
5. **Code moi vao `src2/`** - Khong sua code trong `src/`.
