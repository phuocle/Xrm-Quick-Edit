## 6.1 Tong Quan

AttributeHandler load metadata cua tat ca customizable attributes trong 1 entity, hien thi trong grid de user dich.

**Flow**: Load attributes -> filter excluded -> render grid -> user edit -> save voi MergeLabels -> publish

## 6.3 Exclusion Logic (QUAN TRONG)

Tu `FillTable()` dong 114-137 — day la edge case da xu ly qua nhieu nam:

```typescript
function getExcludedColumns(attributes: AttributeMetadata[]): Set<string> {
  const excluded = new Set<string>();

  for (const attr of attributes) {
    // 1. Rollup fields — companion columns gay CRM exception
    if (attr.FormulaDefinition) {
      if (attr.AttributeType === 'Money') {
        // Rollup Money field sinh ra 3 companion columns
        excluded.add(attr.SchemaName + '_Base');
        excluded.add(attr.SchemaName + '_Date');
        excluded.add(attr.SchemaName + '_State');
      } else {
        // Rollup non-Money field sinh ra 2 companion columns
        excluded.add(attr.SchemaName + '_Date');
        excluded.add(attr.SchemaName + '_State');
      }
    }
    // 2. Non-renameable attributes (system fields)
    else if (attr.IsRenameable && !attr.IsRenameable.Value) {
      excluded.add(attr.SchemaName);
    }
    // 3. BigInt attributes (e.g., versionnumber) — cannot update via metadata API
    else if (attr.AttributeType === 'BigInt') {
      excluded.add(attr.SchemaName);
    }
  }

  return excluded;
}
```

> **Tai sao**: Rollup fields (e.g., `TotalRevenue`) tu dong tao companion fields (`TotalRevenue_Base`, `TotalRevenue_Date`, `TotalRevenue_State`). CRM nem exception khi co gang update labels cua cac companion nay.

## 6.4 FillTable — Build Grid Rows

Tu `FillTable()` dong 108-169:

```typescript
function buildRows(attributes: AttributeMetadata[], component: string): GridRow[] {
  const excluded = getExcludedColumns(attributes);
  const rows: GridRow[] = [];

  for (const attr of attributes) {
    if (excluded.has(attr.SchemaName)) continue;

    const labelObj = component === 'DisplayName' ? attr.DisplayName : attr.Description;
    const localizedLabels = labelObj?.LocalizedLabels;

    if (!localizedLabels || localizedLabels.length === 0) continue;

    const labels: Record<number, string> = {};
    for (const ll of localizedLabels) {
      labels[ll.LanguageCode] = ll.Label;
    }

    rows.push({
      id: attr.MetadataId,
      schemaName: attr.SchemaName,
      labels,
      meta: { attribute: attr },  // Giu original de dung khi save
    });
  }

  return rows;
}
```

## 6.5 Save Logic

Tu `AttributeHandler.SaveOnly()` (dong 192-218):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  // 1. Group changes by row
  const changesByRow = groupChangesByRow(changes);

  // 2. Voi moi row co thay doi
  for (const [rowId, rowChanges] of changesByRow) {
    const row = rows.find(r => r.id === rowId);
    const attribute = row.meta.attribute;

    // 3. Apply changes vao LocalizedLabels
    const component = context.selectedComponent; // 'DisplayName' hoac 'Description'
    const labels = attribute[component].LocalizedLabels;
    applyChanges(rowChanges, labels);

    // 4. Sanitize va PUT
    const cleaned = dataverseService.sanitizeForPut(attribute);
    await dataverseService.updateAttribute(
      context.selectedEntity,
      attribute.MetadataId,
      cleaned
    );
  }

  // 5. Add to solution (neu config co solutionUniqueName)
  // 6. Publish entity
  await publishService.publishEntity(context.selectedEntity);
}
```

### ApplyChanges Helper (Dung chung cho nhieu handlers)

Tu `ApplyChanges()` dong 28-55 — logic nay lap lai o hau het handlers:

```typescript
function applyChanges(
  changes: CellChange[],
  labels: LocalizedLabel[]
): void {
  for (const change of changes) {
    if (!change.newValue) continue;  // Skip empty

    const existing = labels.find(l => l.LanguageCode === change.lcid);
    if (existing) {
      existing.Label = change.newValue;
      existing.HasChanged = true;
    } else {
      // Language chua co label -> them moi
      labels.push({
        LanguageCode: change.lcid,
        Label: change.newValue,
        HasChanged: true,
        IsManaged: false,
        MetadataId: '',
      });
    }
  }
}
```

> **Chu y**: Logic "khong tim thay label cho language nay -> push moi" rat quan trong.
> Dataverse chi tra ve labels cho languages DA CO data, khong phai tat ca installed languages.
