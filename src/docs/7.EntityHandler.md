## 7.2 Load Logic

Tu `EntityHandler.Load()` (dong 128-144):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  // API: GET EntityDefinitions({entityId})
  const entity = await dataverseService.getEntityMetadata(context.selectedEntity);

  const rows: GridRow[] = [];

  // Row 1: Display Name (singular)
  const displayLabels: Record<number, string> = {};
  for (const ll of entity.DisplayName.LocalizedLabels) {
    displayLabels[ll.LanguageCode] = ll.Label;
  }
  rows.push({
    id: entity.MetadataId + '|1',
    schemaName: 'Display Name',
    labels: displayLabels,
    meta: { field: 'DisplayName' },
  });

  // Row 2: Collection Name (plural)
  const collectionLabels: Record<number, string> = {};
  for (const ll of entity.DisplayCollectionName.LocalizedLabels) {
    collectionLabels[ll.LanguageCode] = ll.Label;
  }
  rows.push({
    id: entity.MetadataId + '|2',
    schemaName: 'Collection Name',
    labels: collectionLabels,
    meta: { field: 'DisplayCollectionName' },
  });

  return { rows };
}
```

> **Chu y**: ID dung `MetadataId|1` va `MetadataId|2` de phan biet 2 rows (tu code cu dong 99, 104).

## 7.3 Save Logic

Tu `EntityHandler.SaveOnly()` (dong 146-154):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  const entity = await dataverseService.getEntityMetadata(context.selectedEntity);

  // Apply changes vao dung field
  for (const change of changes) {
    const row = rows.find(r => r.id === change.rowId);
    const field = row.meta.field; // 'DisplayName' hoac 'DisplayCollectionName'
    const labels = entity[field].LocalizedLabels;
    applyChanges([change], labels);
  }

  // PUT entire entity metadata
  await dataverseService.updateEntity(
    context.entityMetadataId,
    entity // voi MergeLabels: true
  );

  // Publish
  await publishService.publishEntity(context.selectedEntity);
}
```

### Diem khac biet voi AttributeHandler

- EntityHandler chi co 1 entity metadata object (khong phai array)
- Save = 1 PUT request (khong phai nhieu requests)
- `DisplayName` maps to component "DisplayName" (dung cho GetComponent)
- `DisplayCollectionName` la field rieng (khong phai component)
