## 4.1 Component Overview

Toolbar chua cac thanh phan:

```
[Solution ▾] [Entity ▾] [Type ▾] [Component ▾] [Load] [Save] [Auto Translate ▾] [Find & Replace]
```

### So sanh voi code cu

| Code cu (w2ui toolbar) | Code moi (Fluent UI) |
|---|---|
| `w2ui.toolbar.items` array | React component voi Fluent `Dropdown`, `Button` |
| `XrmTranslator.FillSolutionSelector()` | `useSolutions()` hook -> Dropdown options |
| `XrmTranslator.FillEntitySelector()` | `useEntities()` hook -> Dropdown options |
| `type` dropdown hardcoded trong InitializeGrid | `TranslationType` enum -> Dropdown |
| `w2ui.toolbar.onClick` handler | Individual `onClick` handlers |

## 4.7 Action Buttons

| Button | Behavior | Disabled khi |
|---|---|---|
| **Load** | Goi `handler.load()` -> populate grid | Dang loading, chua chon entity |
| **Save** | Goi `handler.save()` voi changes | Khong co thay doi, dang saving |
| **Auto Translate** | Mo `AutoTranslateDialog` | Chua load data |
| **Find & Replace** | Mo find/replace panel | Chua load data |

### Config-based visibility

Tu code cu `FetchConfig()`:
- `hideAutoTranslate: true` -> an nut Auto Translate
- `hideFindAndReplace: true` -> an nut Find & Replace

## 4.8 Unsaved Changes Warning

Tu `XrmTranslator.RegisterReloadPrevention()` (dong ~710):

```typescript
// Canh bao khi user navigate away voi unsaved changes
useEffect(() => {
  const handler = (e: BeforeUnloadEvent) => {
    if (hasUnsavedChanges) {
      e.preventDefault();
      e.returnValue = '';
    }
  };
  window.addEventListener('beforeunload', handler);
  return () => window.removeEventListener('beforeunload', handler);
}, [hasUnsavedChanges]);
```
