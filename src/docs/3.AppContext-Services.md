### sanitizeForPut — Chi tiet

Tu code cu `WebApiClient` va cac handler Save functions:

```typescript
sanitizeForPut<T>(obj: T): T {
  return JSON.parse(JSON.stringify(obj, (_key, value) => {
    // Dataverse reject versionnumber (BigInt) trong PUT payload
    if (_key.toLowerCase() === 'versionnumber') return undefined;
    // Strip MetadataId (khong can khi update)
    if (_key === 'MetadataId') return undefined;
    // BigInt values
    if (typeof value === 'bigint') return undefined;
    // Number khong safe
    if (typeof value === 'number' && !Number.isSafeInteger(value) && !Number.isFinite(value)) {
      return undefined;
    }
    return value;
  }));
}
```

> **Tham khao**: Code cu strip `versionnumber` o nhieu noi, vi du `AttributeHandler.js:Save()` dong ~180.

### Publish Entity — Chi tiet

Tu `XrmTranslator.Publish()` (dong ~290-320 code cu):

```typescript
async publishEntity(entityLogicalName: string) {
  const publishXml = `<importexportxml><entities><entity>${entityLogicalName}</entity></entities></importexportxml>`;
  await dataverseAPI.execute({
    operationName: 'PublishXml',
    operationType: 0, // Action
    parameterTypes: {
      ParameterXml: { typeName: 'Edm.String', structuralProperty: 1 }
    },
    ParameterXml: publishXml
  });
}
```

> **Edge case tu code cu**: FormHandler phai doi user ve base language TRUOC khi publish.
> Logic nay se nam trong formHandler.save(), khong phai publishService.
