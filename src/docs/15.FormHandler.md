## 15.1 Tong Quan

FormHandler la handler phuc tap nhat vi **CRM chi tra ve formxml voi labels cua ngon ngu hien tai cua user**. De lay labels tat ca ngon ngu, phai:

1. Doi ngon ngu user sang language A -> fetch form -> parse labels
2. Doi ngon ngu user sang language B -> fetch form -> parse labels
3. ... lap lai cho moi installed language
4. Restore ngon ngu goc cua user

> **Day la "language switching trick"** — edge case lon nhat cua toan bo ung dung.

## 15.2 Load Logic

Tu `FormHandler.Load()` (dong 530-599):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  const entityName = context.selectedEntity;

  // 1. Query forms
  let filter: string;
  if (entityName.toLowerCase() === 'none') {
    // Dashboard mode
    filter = 'formactivationstate eq 1 and iscustomizable/Value eq true and (type eq 0 or type eq 10)';
  } else {
    filter = `objecttypecode eq '${entityName}' and iscustomizable/Value eq true and formactivationstate eq 1`;
  }
  const forms = await dataverseService.fetchRecords('systemform', { filter });

  // 2. LANGUAGE SWITCHING: Voi moi installed language
  const formsByLanguage: Map<number, SystemForm[]> = new Map();

  for (const lang of context.installedLanguages) {
    // Doi ngon ngu user
    await dataverseService.setUserLanguage(context.userId, lang.localeid);

    // Fetch forms (CRM tra ve formxml voi labels cua ngon ngu hien tai)
    const formsInLang = await dataverseService.fetchRecords('systemform', {
      filter,
      select: 'formid,name,type,formxml',
    });

    formsByLanguage.set(lang.localeid, formsInLang);
  }

  // 3. RESTORE ngon ngu goc
  await dataverseService.setUserLanguage(context.userId, context.userLanguage);

  // 4. Hien dialog cho user chon form (hoac auto-select)
  // 5. Parse va merge labels tu tat ca languages
  const selectedFormId = await showFormSelector(forms);
  const rows = mergeFormLabels(selectedFormId, formsByLanguage);

  return { rows };
}
```

## 15.3 FormXML Parsing — DOMParser + TreeWalker

Tu code cu (dong ~40-80, recursive traversal):

```typescript
function parseFormXml(formxml: string, lcid: number): FormNode[] {
  const parser = new DOMParser();
  const doc = parser.parseFromString(formxml, 'text/xml');

  // TreeWalker de traverse form structure
  const walker = doc.createTreeWalker(
    doc.documentElement,
    NodeFilter.SHOW_ELEMENT,
    {
      acceptNode: (node: Element) => {
        // Chi chap nhan nodes co id VA co labels
        const hasId = node.hasAttribute('id');
        const hasLabels = node.querySelector(':scope > labels');
        const isControl = ['tab', 'section', 'cell', 'control'].includes(
          node.tagName.toLowerCase()
        );
        return (hasId && (hasLabels || isControl))
          ? NodeFilter.FILTER_ACCEPT
          : NodeFilter.FILTER_SKIP;
      },
    }
  );

  // Traverse va collect labels
  return traverseTree(walker, lcid);
}
```

## 15.4 Merge Labels Tu Nhieu Languages

```typescript
function mergeFormLabels(
  formId: string,
  formsByLanguage: Map<number, SystemForm[]>
): GridRow[] {
  // 1. Parse formxml cua moi language
  const labelsByNode: Map<string, Record<number, string>> = new Map();
  const hierarchy: Map<string, { parentId: string; name: string }> = new Map();

  for (const [lcid, forms] of formsByLanguage) {
    const form = forms.find(f => f.formid === formId);
    if (!form) continue;

    const nodes = parseFormXml(form.formxml, lcid);
    for (const node of nodes) {
      if (!labelsByNode.has(node.id)) {
        labelsByNode.set(node.id, {});
        hierarchy.set(node.id, { parentId: node.parentId, name: node.name });
      }
      labelsByNode.get(node.id)![lcid] = node.label;
    }
  }

  // 2. Build hierarchical GridRow[] tu labelsByNode
  return buildHierarchyFromFlatMap(labelsByNode, hierarchy);
}
```

## 15.5 Save Logic

Tu `FormHandler.SaveOnly()` (dong 601-635):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  // PHAI WRAP TRONG RunAsBaseLanguage
  const originalLanguage = context.userLanguage;

  try {
    // 1. Doi ve base language
    await dataverseService.setUserLanguage(context.userId, context.baseLanguage);

    // 2. Fetch form moi nhat (co the da thay doi)
    const form = await dataverseService.retrieve('systemform', formId, ['formxml']);

    // 3. Parse formxml
    const parser = new DOMParser();
    const doc = parser.parseFromString(form.formxml, 'text/xml');

    // 4. Apply changes vao XML DOM
    for (const change of changes) {
      const nodeId = change.rowId;
      // Tim node bang id attribute
      const node = doc.querySelector(`[id="${nodeId}"]`);
      if (!node) continue;

      let labelsEl = node.querySelector(':scope > labels');
      if (!labelsEl) {
        labelsEl = doc.createElement('labels');
        node.insertBefore(labelsEl, node.firstChild);
      }

      const existingLabel = labelsEl.querySelector(
        `label[languagecode="${change.lcid}"]`
      );

      if (existingLabel) {
        existingLabel.setAttribute('description', change.newValue);
      } else {
        const newLabel = doc.createElement('label');
        newLabel.setAttribute('description', change.newValue);
        newLabel.setAttribute('languagecode', String(change.lcid));
        labelsEl.appendChild(newLabel);
      }
    }

    // 5. Serialize va update
    const serializer = new XMLSerializer();
    const updatedXml = serializer.serializeToString(doc);

    await dataverseService.updateRecord('systemforms', formId, {
      formxml: updatedXml,
    });

    // 6. Publish
    if (context.selectedEntity.toLowerCase() === 'none') {
      await publishService.publishDashboard(formId);
    } else {
      await publishService.publishEntity(context.selectedEntity);
    }

  } finally {
    // 7. LUON restore ngon ngu goc
    await dataverseService.setUserLanguage(context.userId, originalLanguage);
  }
}
```

## 15.7 Edge Cases

| Edge Case | Xu Ly |
|---|---|
| CRM chi tra labels cua current language | Language switching trick |
| Language switch fail giua chung | `finally` block LUON restore |
| Dashboard vs Form | Khac filter va publish method |
| Cell khong co labels element | Tao moi `<labels>` element |
| config.lockFormCells | Disable editing tren cell nodes |
| Form da bi thay doi boi nguoi khac | Fetch moi nhat truoc khi save |

## 15.8 Performance

- Language switching: N API calls (N = so installed languages) * M forms
- Co the cham voi nhieu languages (5+ languages * 10+ forms = 50+ API calls)
- Khong the parallelize vi language switching la sequential (CRM session)
