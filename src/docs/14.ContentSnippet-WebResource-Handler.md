## PART A: ContentSnippetHandler

### 14A.1 Tong Quan

Content Snippets la thanh phan cua **Dynamics 365 Portals** (adx_contentsnippet). Khac voi cac handlers khac:
- Dung **Portal languages** (khong phai org installed languages)
- Co the **tao record moi** (khong chi update existing)
- **2-level hierarchy**: Website -> Snippets
- **Khong can publish** (direct CRUD)

### 14A.2 Load

  // 3. Group by website -> snippet name
  const rows = buildContentSnippetRows(snippets, portalLanguages);

  // 4. Override columns — portal languages thay vi org languages

### 14A.4 Save — Create or Update

Tu `Save()` (dong 219-249) — KHAC BIET: Co the tao record moi:

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  for (const change of changes) {
    const [websiteId, snippetName] = change.rowId.split('|');

    // Tim snippet record hien co cho language nay
    const existingSnippet = findExistingSnippet(websiteId, snippetName, change.lcid);

    if (existingSnippet) {
      // Update
      await dataverseService.updateRecord('adx_contentsnippets', existingSnippet.id, {
        adx_value: change.newValue,
      });
    } else {
      // CREATE record moi cho language nay
      const portalLanguageId = findPortalLanguageForWebsite(websiteId, change.lcid);
      if (!portalLanguageId) continue;  // Language khong enabled cho website nay

      await dataverseService.createRecord('adx_contentsnippets', {
        adx_name: snippetName,
        adx_value: change.newValue,
        'adx_websiteid@odata.bind': `/adx_websites(${websiteId})`,
        'adx_contentsnippetlanguageid@odata.bind': `/adx_websitelanguages(${portalLanguageId})`,
      });
    }
  }
  // KHONG can publish
}
```

### 14A.5 Edge Cases

- Portal language validation: Skip neu language khong enabled cho website
- HTML encoding: `encodeTags()` khi load, `decodeTags()` khi save
- Compound ID: `websiteId|snippet_name`
- Khong co publish step

## PART B: WebResourceHandler

### 14B.1 Tong Quan

Web Resources la JSON files chua key-value translations, organized theo language:
- `MyScript.1033.js` (English), `MyScript.1036.js` (French)
- Content la base64-encoded JSON: `{ "greeting": "Hello", "farewell": "Goodbye" }`

### 14B.2 Load

Tu `WebResourceHandler.Load()` (dong 163-214):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  const baseLanguage = context.baseLanguage;

  // 1. Tim base language web resources: name contains '{baseLanguage}.js'
  const baseResources = await dataverseService.fetchRecords('webresource', {
    filter: `contains(name, '${baseLanguage}.js')`,
    select: 'webresourceid,name,content',
  });

  const rows: GridRow[] = [];

  for (const base of baseResources) {
    // 2. Extract grouping key: "MyScript" tu "MyScript.1033.js"
    const groupKey = extractGroupKey(base.name, baseLanguage);

    // 3. Find all language variants
    const allVariants = await dataverseService.fetchRecords('webresource', {
      filter: `contains(name, '${groupKey}')`,
      select: 'webresourceid,name,content',
    });

    // 4. Parse each variant
    const languageContents: Map<number, Record<string, string>> = new Map();
    for (const variant of allVariants) {
      const lcid = extractLcidFromName(variant.name);
      const content = JSON.parse(b64DecodeUnicode(variant.content));
      languageContents.set(lcid, content);
    }

    // 5. Build rows — parent = group, children = properties
    const allKeys = getAllPropertyKeys(languageContents);
    const parent: GridRow = {
      id: groupKey,
      schemaName: groupKey,
      labels: {},
      children: [],
    };

    for (const key of allKeys) {
      const labels: Record<number, string> = {};
      for (const [lcid, content] of languageContents) {
        if (content[key]) labels[lcid] = content[key];
      }
      parent.children!.push({
        id: `${groupKey}|${key}`,
        schemaName: key,
        labels,
      });
    }

    rows.push(parent);
  }

  return { rows };
}
```

### 14B.3 Base64 Unicode

```typescript
function b64DecodeUnicode(str: string): string {
  return decodeURIComponent(
    atob(str).split('').map(c =>
      '%' + ('00' + c.charCodeAt(0).toString(16)).slice(-2)
    ).join('')
  );
}

function b64EncodeUnicode(str: string): string {
  return btoa(
    encodeURIComponent(str).replace(/%([0-9A-F]{2})/g, (_, p1) =>
      String.fromCharCode(parseInt(p1, 16))
    )
  );
}
```

### 14B.4 Save

Tu `WebResourceHandler.Save()` (dong 216-275):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  // 1. Group changes by groupKey + lcid
  // 2. Voi moi (groupKey, lcid): load existing content -> merge -> encode -> update/create

  for (const [groupKey, lcidChanges] of groupedChanges) {
    for (const [lcid, propertyChanges] of lcidChanges) {
      const existingVariant = findVariant(groupKey, lcid);

      if (existingVariant) {
        // Update existing
        const content = JSON.parse(b64DecodeUnicode(existingVariant.content));
        for (const change of propertyChanges) {
          const propertyKey = change.rowId.split('|')[1];
          content[propertyKey] = change.newValue;
        }
        await dataverseService.updateRecord('webresources', existingVariant.id, {
          content: b64EncodeUnicode(JSON.stringify(content)),
        });
        updatedIds.push(existingVariant.id);
      } else {
        // Create new web resource for this language
        const newName = generateResourceName(groupKey, lcid);
        const content = {};
        for (const change of propertyChanges) {
          content[change.rowId.split('|')[1]] = change.newValue;
        }
        const result = await dataverseService.createRecord('webresources', {
          name: newName,
          content: b64EncodeUnicode(JSON.stringify(content)),
          webresourcetype: 3, // JS
        });
        updatedIds.push(result.id);
      }
    }
  }

  // 3. Publish web resources
  await publishService.publishWebResources(updatedIds);
}
```

### 14B.5 Edge Cases

- Base64 Unicode encoding/decoding (khong dung atob/btoa truc tiep vi UTF-8)
- LCID extraction tu filename bang regex: `/([0-9]+)\.js/`
- Tao web resource moi neu language variant chua ton tai
- Compound ID: `groupKey|propertyName`
- Publish: PublishWebResources (khong phai entity publish)
