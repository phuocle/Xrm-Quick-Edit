## 8.1 Tong Quan

ViewHandler va ChartHandler co chung pattern:
1. Query records bang OData
2. Voi moi record, goi `RetrieveLocLabelsRequest` de lay labels da cac ngon ngu
3. Hien thi trong grid (flat, khong hierarchical)
4. Save bang `SetLocLabelsRequest`

## 8.2 ViewHandler — Load

Tu `ViewHandler.Load()` (dong 133-181):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  // 1. Query views cua entity
  const views = await dataverseService.fetchRecords('savedquery', {
    filter: `returnedtypecode eq '${context.selectedEntity}' and iscustomizable/Value eq true`,
    orderby: 'savedqueryid asc'
  });

  // 2. Voi moi view, lay labels
  const rows: GridRow[] = [];
  for (const view of views) {
    const labels = await dataverseService.retrieveLocLabels(
      'savedqueries',
      view.savedqueryid,
      'name',
      true  // IncludeUnpublished
    );

    const labelMap: Record<number, string> = {};
    for (const ll of labels.Label.LocalizedLabels) {
      labelMap[ll.LanguageCode] = ll.Label;
    }

    rows.push({
      id: view.savedqueryid,
      schemaName: viewTypeMap[view.querytype] || `Type ${view.querytype}`,
      labels: labelMap,
      meta: { querytype: view.querytype, labels },
    });
  }

  return { rows };
}
```

## 8.3 ViewHandler — Save

Tu `ViewHandler.SaveOnly()` (dong 183-211):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  const changesByRow = groupChangesByRow(changes);

  for (const [rowId, rowChanges] of changesByRow) {
    const row = rows.find(r => r.id === rowId);
    const labels = row.meta.labels.Label.LocalizedLabels;
    applyChanges(rowChanges, labels);

    // SetLocLabelsRequest
    await dataverseService.setLocLabels({
      Labels: labels,
      EntityMoniker: {
        '@odata.type': 'Microsoft.Dynamics.CRM.savedquery',
        savedqueryid: rowId,
      },
      AttributeName: 'name',
    });
  }

  // AddToSolution: ComponentType = 26 (SavedQuery)
  // Publish entity
  await publishService.publishEntity(context.selectedEntity);
}
```

## 8.4 ChartHandler

Gan giong ViewHandler, chi khac:
- Entity: `savedqueryvisualization` thay vi `savedquery`
- Filter: `primaryentitytypecode` thay vi `returnedtypecode`
- schemaName: Luon la `'Chart'` (code cu dong 72)
- OData type: `Microsoft.Dynamics.CRM.savedqueryvisualization`
- ID field: `savedqueryvisualizationid`

## 8.5 API Pattern Chung: RetrieveLocLabels / SetLocLabels

Day la pattern dung cho Views, Charts, va FormMeta. Can wrap trong dataverseService:

```typescript
// dataverseService.ts
async retrieveLocLabels(
  entitySetName: string,
  recordId: string,
  attributeName: string,
  includeUnpublished: boolean
): Promise<Label> {
  // RetrieveLocLabelsRequest
  return dataverseAPI.execute({
    operationName: 'RetrieveLocLabels',
    operationType: 1, // Function
    parameterTypes: { ... },
    EntityMoniker: `{'@odata.id':'${entitySetName}(${recordId})'}`,
    AttributeName: `'${attributeName}'`,
    IncludeUnpublished: includeUnpublished,
  });
}

async setLocLabels(payload: {
  Labels: LocalizedLabel[];
  EntityMoniker: object;
  AttributeName: string;
}): Promise<void> {
  // SetLocLabelsRequest
  return dataverseAPI.execute({
    operationName: 'SetLocLabels',
    operationType: 0, // Action
    parameterTypes: { ... },
    ...payload,
  });
}
```
