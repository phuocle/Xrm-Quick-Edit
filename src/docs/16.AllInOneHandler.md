## 16.1 Tong Quan

AllInOneHandler cho phep user load **tat ca translation types cung luc** trong 1 grid. Flow:
1. Load tung handler tuan tu
2. Prefix record IDs de tranh trung lap
3. Gom vao groups trong grid
4. Save: tach records theo prefix, goi handler goc

## 16.3 Load

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  const allRows: GridRow[] = [];

  // Load tung handler TUAN TU (vi moi handler co the thay doi state)
  const handlers: Array<{ prefix: string; name: string; handler: IHandler }> = [
    { prefix: 'attr~', name: 'Attributes', handler: attributeHandler },
    { prefix: 'opts~', name: 'Option Sets', handler: optionSetHandler },
    { prefix: 'view~', name: 'Views', handler: viewHandler },
    { prefix: 'fmta~', name: 'Form Names', handler: formMetaHandler },
    { prefix: 'enty~', name: 'Entity Names', handler: entityHandler },
    { prefix: 'rels~', name: 'Relationships', handler: relationshipHandler },
    { prefix: 'chrt~', name: 'Charts', handler: chartHandler },
    { prefix: 'bpfs~', name: 'Business Process Flows', handler: bpfHandler },
  ];

  for (const { prefix, name, handler } of handlers) {
    try {
      const result = await handler.load(context);
      const prefixedRows = prefixRows(result.rows, prefix);

      // Wrap trong group node (non-editable)
      allRows.push({
        id: `group~${prefix}`,
        schemaName: `--- ${name} ---`,
        labels: {},
        children: prefixedRows,
        meta: { isGroupNode: true, handlerPrefix: prefix },
      });
    } catch (error) {
      console.warn(`Failed to load ${name}:`, error);
      // Continue voi handlers khac
    }
  }

  // Forms: Load rieng (moi form la 1 group)
  try {
    const formResults = await formHandler.loadAllForms(context);
    for (const formResult of formResults) {
      const prefix = `form~${formResult.formId}~`;
      const prefixedRows = prefixRows(formResult.rows, prefix);

      allRows.push({
        id: `group~${prefix}`,
        schemaName: `--- Form: ${formResult.formName} ---`,
        labels: {},
        children: prefixedRows,
        meta: { isGroupNode: true, handlerPrefix: prefix, formId: formResult.formId },
      });
    }
  } catch (error) {
    console.warn('Failed to load Forms:', error);
  }

  return { rows: allRows };
}
```

## 16.4 Prefix Functions

```typescript
function prefixRows(rows: GridRow[], prefix: string): GridRow[] {
  return rows.map(row => ({
    ...row,
    id: `${prefix}${row.id}`,
    children: row.children?.map(child => ({
      ...child,
      id: `${prefix}${child.id}`,
      children: child.children?.map(grandchild => ({
        ...grandchild,
        id: `${prefix}${grandchild.id}`,
      })),
    })),
    meta: { ...row.meta, _allInOnePrefix: prefix },
  }));
}

function stripPrefix(rows: GridRow[], prefix: string): GridRow[] {
  return rows.map(row => ({
    ...row,
    id: row.id.replace(prefix, ''),
    children: row.children?.map(child => ({
      ...child,
      id: child.id.replace(prefix, ''),
      children: child.children?.map(grandchild => ({
        ...grandchild,
        id: grandchild.id.replace(prefix, ''),
      })),
    })),
  }));
}
```

> **3-level nesting**: BPF co grandchildren (BPF -> Stage -> Field).
> Prefix phai apply o 3 levels.

## 16.5 Save

Tu `AllInOneHandler.Save()` (dong 303-418):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  // 1. Group changes by prefix
  const changesByPrefix = new Map<string, CellChange[]>();
  for (const change of changes) {
    const prefix = extractPrefix(change.rowId);
    if (!changesByPrefix.has(prefix)) changesByPrefix.set(prefix, []);
    changesByPrefix.get(prefix)!.push({
      ...change,
      rowId: change.rowId.replace(prefix, ''),  // Strip prefix
    });
  }

  // 2. Save tung handler
  for (const [prefix, handlerChanges] of changesByPrefix) {
    const handler = getHandlerByPrefix(prefix);
    const handlerRows = getRowsByPrefix(rows, prefix);
    const strippedRows = stripPrefix(handlerRows, prefix);

    if (prefix.startsWith('form~')) {
      // Form: wrap trong RunAsBaseLanguage
      await context.runAsBaseLanguage(async () => {
        await handler.save(strippedRows, handlerChanges, context);
      });
    } else {
      await handler.save(strippedRows, handlerChanges, context);
    }
  }

  // 3. PublishAll 1 lan (thay vi publish tung entity)
  await publishService.publishAll();
}
```

## 16.6 Edge Cases

| Edge Case | Xu Ly |
|---|---|
| Handler load fail | console.warn, continue voi handlers khac |
| Prefix conflict | Moi handler co prefix unique |
| 3-level nesting (BPF) | Prefix apply o 3 levels |
| Form per-form groups | Moi form co prefix rieng `form~{formId}~` |
| Save order matters | Form saves wrap trong RunAsBaseLanguage |
| Single publish | PublishAllXml 1 lan thay vi per-handler |

## Acceptance Criteria

- [ ] Load: Tat ca handler types duoc load tuan tu
- [ ] Load: Moi type la 1 group node (non-editable)
- [ ] Prefix: IDs duoc prefix dung, khong trung lap
- [ ] 3-level nesting: BPF grandchildren co prefix dung
- [ ] Forms: Moi form la 1 group rieng voi prefix `form~{formId}~`
- [ ] Save: Changes duoc group theo prefix, strip prefix truoc khi goi handler
- [ ] Save: Forms wrap trong RunAsBaseLanguage
- [ ] Publish: PublishAllXml 1 lan cuoi cung
- [ ] Error: Handler fail khong lam crash toan bo load
