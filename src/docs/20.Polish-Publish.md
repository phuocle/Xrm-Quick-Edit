## 20.2 Error Handling

### Notifications

Dung `toolboxAPI.utils.showNotification`:

```typescript
// Success
toolboxAPI.utils.showNotification('Saved and published successfully', 'success');

// Error
toolboxAPI.utils.showNotification(`Save failed: ${error.message}`, 'error');

// Warning
toolboxAPI.utils.showNotification('Some translations could not be saved', 'warning');
```

### Error Boundaries

```tsx
import { ErrorBoundary } from 'react-error-boundary';

<ErrorBoundary
  fallback={<div>Something went wrong. Please reload the tool.</div>}
  onError={(error) => console.error('Tool error:', error)}
>
  <App />
</ErrorBoundary>
```

### Common Errors

| Error | Xu Ly |
|---|---|
| 401 Unauthorized | "Session expired. Reconnect in PPTB." |
| 403 Forbidden | "Insufficient permissions for this entity." |
| 412 Precondition Failed | "Record modified by another user. Reload and try again." |
| Network error | "Connection lost. Check network and try again." |
| Translation API error | "Translation failed: [provider error message]" |

## 20.3 Connection Events

Lang nghe PPTB connection events:

```typescript
useEffect(() => {
  const handleConnectionChange = (newConnection: DataverseConnection) => {
    // Re-initialize: reload solutions, entities, etc.
    reinitialize(newConnection);
  };

  toolboxAPI.events.on('connectionChanged', handleConnectionChange);
  return () => toolboxAPI.events.off('connectionChanged', handleConnectionChange);
}, []);
```

## 20.4 Config Support

Migrate config tu web resource sang `toolboxAPI.settings`:

```typescript
interface ToolConfig {
  entityWhiteList: string[];
  hideAutoTranslate: boolean;
  hideFindAndReplace: boolean;
  hideLanguagesByDefault: boolean;
  lockedLanguages: number[];
  solutionUniqueName: string;
  lockFormCells: boolean;
}

async function loadConfig(): Promise<ToolConfig> {
  const config = await toolboxAPI.settings.get('toolConfig');
  return config ? JSON.parse(config) : defaultConfig;
}
```
