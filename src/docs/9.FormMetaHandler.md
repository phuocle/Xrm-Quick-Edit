## 9.2 Load Logic

Tu `FormMetaHandler.Load()` (dong 124-173):

```typescript
async load(context: AppContextType): Promise<LoadResult> {
  let filter: string;

  if (context.selectedEntity.toLowerCase() === 'none') {
    // Dashboard mode — khong co entity
    filter = 'formactivationstate eq 1 and iscustomizable/Value eq true and (type eq 0 or type eq 10)';
  } else {
    // Normal entity forms
    filter = `objecttypecode eq '${context.selectedEntity}' and iscustomizable/Value eq true and formactivationstate eq 1`;
  }

  const forms = await dataverseService.fetchRecords('systemform', { filter });

  const rows: GridRow[] = [];
  for (const form of forms) {
    const labels = await dataverseService.retrieveLocLabels(
      'systemforms', form.formid, 'name', true
    );

    const labelMap: Record<number, string> = {};
    for (const ll of labels.Label.LocalizedLabels) {
      labelMap[ll.LanguageCode] = ll.Label;
    }

    rows.push({
      id: form.formid,
      schemaName: formTypeMap[form.type] || `Type ${form.type}`,
      labels: labelMap,
      meta: { type: form.type, labels },
    });
  }

  return { rows };
}
```

## 9.3 Edge Case: Dashboard vs Form

Tu `FormMetaHandler.Save()` (dong 211-233):

```typescript
async save(rows: GridRow[], changes: CellChange[], context: AppContextType): Promise<void> {
  // ... save logic (SetLocLabelsRequest) ...

  // CRITICAL: Publish khac nhau
  if (context.selectedEntity.toLowerCase() === 'none') {
    // Dashboard: dung PublishDashboard thay vi Publish entity
    // AddToSolution voi componentType = SystemForm, includeSubComponents = true, addRequiredComponents = true
    await publishService.publishDashboard(updatedFormIds);
  } else {
    // Normal form: Publish entity
    await publishService.publishEntity(context.selectedEntity);
  }
}
```

> **Chu y tu code cu dong 202-208**: Khi entity la "none" (dashboard), AddToSolution phai truyen
> `includeSubComponents = true` va `addRequiredComponents = true`.

## 9.5 API Calls

| Action | Method | Details |
|---|---|---|
| Load | GET | `systemforms?$filter=...` |
| Load labels | Function | `RetrieveLocLabelsRequest` per form |
| Save | Action | `SetLocLabelsRequest` per form |
| Publish (form) | Action | `PublishXml` with entity |
| Publish (dashboard) | Action | `PublishXml` with dashboard IDs |
| AddToSolution | Action | ComponentType = 60 (SystemForm) |
